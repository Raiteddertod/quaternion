# Quaternion Attitude Controller

Библиотека для вычисления желаемых угловых скоростей ориентации твёрдого тела (quadrotor / UAV) на основе кватернионов. Реализация контроллера ориентации по статье:

> **Faessler et al.** "Automatic Re-Initialization and Failure Recovery for Aggressive Flight with a Monocular Vision-Based Quadrotor", ICRA 2015.

## Что делает библиотека

Контроллер решает задачу **преобразования желаемого ускорения и референсного рысканья в команды угловых скоростей** в связанной системе координат:

### Входные данные
| Параметр   | Описание                                      | Единицы |
|------------|-----------------------------------------------|---------|
| `q_hat`    | Текущий кватернион ориентации                 | -       |
| `a_des`    | Желаемое ускорение в мировой СК (от позиционного контура) | м/с²    |
| `psi_ref`  | Желаемое рысканье (heading)                   | рад     |

### Выходные данные
| Параметр      | Описание                                                      | Уравнение |
|---------------|---------------------------------------------------------------|-----------|
| `p_des`       | Желаемая угловая скорость по крену (в связанной СК)           | (15)      |
| `q_des`       | Желаемая угловая скорость по тангажу (в связанной СК)         | (15)      |
| `r_des`       | Желаемая угловая скорость по рысканью (в связанной СК)        | (20)      |
| `G_des`       | Полная желаемая ориентация (кватернион) — промежуточный результат | —         |

> **Важно:** Вектор тяги всегда направлен по оси Z связанной системы координат (как у мультиротора с горизонтальными пропеллерами).

## Быстрый запуск

### 1. Основной демонстрационный скрипт (`basic1.py`)

Этот скрипт показывает работу контроллера при восстановлении горизонтальной ориентации:

```bash
python examples/basic1.py
```

**Что происходит при запуске:**

- Задаётся начальный наклон (по умолчанию Roll=45°, Pitch=30°, Yaw=0°)
- Контроллер пытается выровнять аппарат в горизонтальное положение при `a_des = [0, 0, 9.81]`
- Строятся два графика:
  - Углы Эйлера (текущие vs желаемые)
  - Команды угловых скоростей `p_des`, `q_des`, `r_des`
- Запускается **3D-анимация** с элементами управления:
  - Кнопки **Play / Pause**
  - **Reverse** (воспроизведение назад)
  - **Restart**
- На анимации отображаются ключевые векторы из статьи:
  - `e_z,des_B` (желаемая ось Z)
  - `n` (ось вращения)
  - `B_n` (ось вращения в связанной СК)
  - Текущий угол ошибки `α`

### 2. Интерактивный визуализатор кватернионов

## Что делает `attitude_controller`

Основная функция находится здесь:

```python
from quaternion.attitude_controller import compute_desired_rates

p_des, q_des, r_des, G_des = compute_desired_rates(
    q_hat=q,
    a_des=np.array([0.0, 0.0, 9.81]),
    psi_ref=0.0,
    p_rp=8.0,      # коэффициент усиления roll/pitch
    p_yaw=4.0      # коэффициент усиления yaw
)
```

### Внутренняя логика (две части):

**Часть 1 — Крен и Тангаж (уравнения 10–15)**
- Вычисляет текущую ось Z корпуса (`e_z_B`)
- Определяет желаемую ось Z из вектора ускорения (`e_z,des_B`)
- Находит кватернион ошибки между ними
- Выдаёт команды `p_des` и `q_des`

**Часть 2 — Рысканье (уравнения 16–20)**
- Строит промежуточную систему координат C по `psi_ref`
- Формирует полную желаемую ориентацию `G_des` (все три оси)
- Вычисляет ошибку по рысканью
- Выдаёт команду `r_des`

### Как строится полная желаемая ориентация `G_des`

1. `e_z,des^B = a_des / ||a_des||`
2. Строится промежуточный базис C по углу `psi_ref`
3. `e_x,des^B = normalize(e_y^C × e_z,des^B)`
4. `e_y,des^B = normalize(e_z,des^B × e_x,des^B)`
5. Собирается матрица поворота `R_des = [e_x, e_y, e_z]`
6. Матрица преобразуется в кватернион
